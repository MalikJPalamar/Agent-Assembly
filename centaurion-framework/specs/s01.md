# s01 — Supabase schema (Neurowellness sensing layer)

Milestone: M0. Layer: Neurowellness Stack.

## Goal
Define the initial relational schema for the sensing layer as plain SQL plus a
small Node module that exposes the schema and validates biomarker readings.

## Deliverables
1. `src/s01/schema.sql` — tables `users`, `sessions`, `biomarker_readings`
   (reading has `user_id`, `session_id`, `metric` text, `value` numeric,
   `unit` text, `recorded_at` timestamptz, `source` text e.g. `terra`).
   Include primary keys, foreign keys and an index on `(user_id, recorded_at)`.
2. `src/s01/index.js` — exports `TABLES` (array of table names),
   `validateReading(reading)` returning `{ ok: boolean, errors: string[] }`,
   and `loadSchemaSql()` returning the SQL text.
3. `tests/s01.test.js` — jest tests for the exports above (valid reading,
   missing fields, non-numeric value, SQL contains each table).

## Constraints
- No external runtime dependencies; Node 20 + jest only.
- Pure functions, no network calls.
